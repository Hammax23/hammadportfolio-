2) Google Search Console — Detail

GSC bataata hai Google ne tumhari site ko search results mein kaise treat kiya: kaunsi query, kitni impressions, kitne clicks, kaunsi page index hai ya error.

Kab kholo?

  • Haftay mein 2 baar (15–20 minutes)
  • Naya page publish karne ke turant baad (URL Inspection)
  • Jab traffic sudden drop ho

Kya dekho? (priority order)

  1. Performance
    Queries, pages, countries, devices. Note karo:
    • Top queries jahan impression hai lekin CTR kam
    • Queries jahan tum already page-1 near ho (improve title/meta)
  2. Page indexing
    Kaunsi URLs indexed / not indexed / error. Errors fix karo pehle.
  3. URL Inspection
    Important URLs pe Request indexing (spam mat karo roz).
  4. Sitemaps
    sitemap.xml Success hona chahiye. Dobara roz submit mat karo.

Tumhari site ke liye practical use

  • Home, /work, /about, /expertise, /contact pe focus
  • Agar query aaye “full stack developer” → title/H1/about copy align karo
  • Agar /work pe clicks hain → projects ke names aur tech stack clear rakho
Gur: GSC = school result card. Yahan se pata chalta hai Google ne accept kiya ya nahi. Keywords “rank” ka final proof yahi se aata hai (queries + position).

3) Bing Webmaster Tools — Detail

Bing alag search engine hai (Yahoo/DuckDuckGo partners bhi). Traffic Google se kam hota hai, lekin free extra reach + IndexNow se fast notify milta hai.

Kab kholo?

  • Mahine mein 1–2 baar kaafi
  • Nayi site / bari update ke baad IndexNow / sitemap check

Kya use karo?

  • Sitemaps: same https://www.hammadiftikhar.com/sitemap.xml
  • URL Inspection: important pages submit
  • IndexNow: pehle se setup; bari update pe dobara submit useful
  • Keyword Research: kabhi idea ke liye; Google + Ahrefs/Semrush stronger
  • Backlinks: data late aa sakta hai; empty = normal nayi site pe
Gur: 80% energy Google (GSC + GA4) pe. Bing = bonus lane, primary battlefield nahi.

4) Google Analytics 4 (GA4) — Detail

GA4 batata hai: kitne log aaye, kahan se aaye, kaunsa page dekha, kitni der ruke, Contact/Hire tak gaye ya bounce kiya.

GSC vs GA4 (confusion khatam)

GSC GA4
Search query: “hire full stack” User ne /contact open kiya?
Click mila Google se 10 second baad bounce?
Sirf Google Search Google + LinkedIn + Direct + referral sab

Kab kholo?

  • Haftay mein 1–2 baar
  • Campaign / LinkedIn post ke baad Realtime check

Kya dekho?

  1. Realtime — abhi traffic aa rahi hai ya nahi (tag test)
  2. Reports → Acquisition — source: Organic, Direct, Referral, Social
  3. Engagement → Pages and screens — top pages
  4. Retention — wapas aa rahe hain ya nahi

Portfolio ke liye success metrics

  • /contact visits
  • Hire drawer / form opens (agar event set ho)
  • WhatsApp clicks (agar track karo)
  • /work pe time on page
Gur: GSC = door se aana. GA4 = ghar ke andar kya kiya. Dono milake poori kahani banati hai.

5) Ahrefs — Detail

Ahrefs research weapon hai. Ye batata hai competitors ke backlinks, top pages, keyword difficulty, aur content gaps. Web Analytics script bhi site pe laga hai.

Kab kholo?

  • Hafte mein 1 baar research session (30–45 min)
  • Jab naya case-study / service page likhna ho

Core features kaise use karo

  1. Site Explorer (apni site)
    • Domain Rating / backlinks count over time
    • Top pages by traffic potential
    • Referring domains quality (spam vs real sites)
  2. Site Explorer (competitor)
    • Unke top organic pages dekho
    • Unke backlinks kahan se aaye (guest post, directories, clients)
    • Jo easy links tum bhi le sakte ho, un pe action
  3. Keywords Explorer
    • Volume, KD (difficulty), parent topic
    • Portfolio ke liye hire-intent keywords prefer karo
  4. Content Gap
    • Competitor rank karta hai, tum nahi → content idea list
  5. Web Analytics (installed)
    • Ahrefs wala traffic view; GSC/GA ke saath compare

Freelance ke liye best keyword types

  • hire full stack developer
  • next.js developer for hire
  • react native app developer
  • laravel saas developer
  • project-based: chauffeur app, school management system, etc.
Gur: Ahrefs se plan banta hai. GSC/GA se result check hota hai. Roz Ahrefs kholna zaroori nahi.

6) Semrush — Detail

Semrush bhi all-in-one hai (keywords, site audit, position tracking, competitors). Ahrefs jaisa overlap bohot hai. Dono ko roz parallel mat chalao.

Practical split (recommended)

Ahrefs pe focus Semrush pe focus
Backlinks + competitor link research Site Audit (technical issues)
Content gap / keyword difficulty deep dive Position tracking (weekly ranks)
Referring domains quality On-page / content ideas + topic reports

Semrush weekly use

  1. Site Audit chalao → errors/warnings fix (broken links, missing meta, etc.)
  2. Position Tracking mein 10–20 keywords add karo
  3. 1 competitor overview → unke top keywords note
Gur: Budget/time bachane ke liye ek primary research tool choose karo (Ahrefs YA Semrush). Doosra optional backup.

7) Keywords ko site pe kaise use karein

Keyword select karna half kaam hai. Use = sahi jagah natural placement.

Jagah Example
Title tag Hammad Iftikhar | Full Stack Developer
Meta description Hire a full stack developer for Next.js, React Native…
H1 Keyword ek dafa, natural
First paragraph Service + proof (projects)
Image alt Meaningful, keyword stuffed nahi
Internal links /work ↔ /expertise ↔ /contact

Rule: 1 page = 1 primary keyword. 3–5 natural mentions. Stuffing mat karo.

8) Backlinks — short gur

Backlink = doosri website pe tumhari site ka link. Google isay trust vote samajhta hai.

  • Achhi: client credit, LinkedIn/GitHub/Upwork, real guest posts, partner pages
  • Buri: spam directories, paid junk farms, fake comments

Check kahan: Ahrefs Site Explorer / Bing Backlinks (late data). Banani kahan: real relationships + project credits.

9) Weekly Routine (30–40 minutes) — Print & Follow

  1. GSC Performance (10 min) — top queries + CTR notes
  2. GA4 (8 min) — sources + top pages + contact interest
  3. Ahrefs YA Semrush (12 min) — 5 keywords OR 1 competitor OR audit issues
  4. 1 Action (10 min) — title improve / LinkedIn post / backlink ask / content tweak

10) Monthly Routine

  • GSC indexing errors clean
  • Ahrefs: referring domains badhe ya nahi
  • Semrush audit score improve
  • 1 case-study style post (SARJ / SaaS / stack)
  • Profiles sync: LinkedIn, Upwork, GitHub website URL

11) Daily (optional, 5 minutes)

  • LinkedIn engage / 1 useful comment with authority
  • Spam tools checking avoid — daily GSC refresh zaroori nahi

12) Mat karo (common mistakes)

  • Har din Request indexing spam
  • Sitemap roz resubmit
  • Ahrefs + Semrush dono mein same research double
  • Keyword stuffing titles
  • Spam backlink buying
  • Sirf tools dekhna, action na lena
